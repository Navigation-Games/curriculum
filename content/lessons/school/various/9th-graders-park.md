## Goals

### Orienteering Goals
- Use a clue sheet to find checkpoints in order
- Orient a map using landmarks and confirm checkpoints
- Read an orienteering map and connect symbols to real features
- Navigate independently to checkpoints using a map
- Observe terrain and represent it using map symbols and colors

A 90-minute station rotation for ~75 ninth graders. Three groups of 25 rotate through three 30-minute stations, each led by a different instructor. Every student gets Animal-O/Geometric-O, Score-O, and a mapmaking exercise.

### Station A: Animal-O and Geometric-O

**Led by:** Maija
**Time:** 30 minutes

Set up animal-picture checkpoints in a geometric pattern with colored landmark cones at corners. The first group helps set up the cones (5 minutes). Split each group of 25 into two smaller groups (A and B) so students aren't waiting.

1. **Set up cones** (5 min, first group only)
2. [**Animal-O**](/activities/core/animal-o) (10 min): hand out clue sheets. Students find checkpoints in order, confirm the animal at each one. Brief intro to establish the format: clue sheet, sequence, confirm.
3. **Water break** (2 min)
4. [**Geometric-O**](/activities/core/geometric-o) (15 min): transition to pattern maps. Students orient the map using the colored cones and visit checkpoints in order. Progress through harder maps as students finish.
5. **Transition** (5 min): move to the next station.

### Station B: Score-O

**Led by:** Mikayla and Marius
**Time:** 30 minutes

Place checkpoint streamers around the Score-O area. Have the poster-sized orienteering map ready for the intro. Mikayla knows the checkpoint system. Split each group of 25 into two smaller groups (A and B).

1. **Introduce the orienteering map** (5 min): explain map symbols and how to orient the map so it matches the terrain.
2. **Set up checkpoint locations on the poster map** (5 min): using the poster-sized map, show where checkpoints are. Students match symbols on the map to features they can see.
3. **Copy the course onto blank maps** (5 min): students transfer the checkpoint locations from the poster map onto their own blank orienteering maps.
4. **Water break** (2 min)
5. [**Score-O**](/activities/core/score-o) (10 min): students navigate to as many checkpoints as possible within the time limit, using their maps.
6. **Clean up** (5 min): pick up the streamers.

### Station C: Draw a Map

**Led by:** Anlinn and Izzy
**Time:** 30 minutes

Have partially completed orienteering maps ready (one per student) with some features and colors already filled in. Have real orienteering maps of the park available for comparison. Split each group of 25 into two smaller groups (A and B).

1. **Introduce the orienteering map** (5 min): explain map symbols and how to orient the map so it matches the terrain.
2. **Draw the map** (20 min): students walk around the area and complete their partially finished maps by adding missing features and colors. They observe the terrain and decide which map symbols to use for what they see.
3. **Compare to the orienteering map** (5 min): gather students and compare their hand-drawn maps to the real orienteering map of the same area. What did they notice? What did they miss? What surprised them?
4. **Transition** (5 min): move to the next station.

### Notes

- Each station splits 25 students into two smaller groups (A and B) for manageability
- Station A's cone setup only happens with the first group; subsequent groups find it ready
- Station B's streamer pickup only happens with the last group (or is done by instructors between rotations)
- The mapmaking station (C) does not require prior orienteering experience, so rotation order is flexible
