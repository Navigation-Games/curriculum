# Maps

You do not need a professional orienteering map to start teaching orienteering. The early activities in the curriculum (Boundary Run, Gathering, Animal-O, Geometric-O) use no map at all, or use simple pattern maps you can draw yourself. But as students progress to Symbol-O, Score-O, and Point-to-Point, a real orienteering map of your site makes a big difference.

## Getting a Map Made

### OUSA Youth Mapping Project

Orienteering USA runs the [Youth Mapping Project (YMP)](https://orienteeringusa.org/resources/ymp/), which connects schools and youth organizations with professional orienteering cartographers. OUSA grants can cover up to half the mapping cost.

**How to apply:**

1. Visit the [YMP page](https://orienteeringusa.org/resources/ymp/) and review the program
2. Complete the [application form](https://docs.google.com/forms/d/e/1FAIpQLSciJF8ZFi8hqO7OetK17u4A_Te6uxw6Gv6ExeVFRe6Zm-a_Sg/viewform)
3. Include a clear description of your area with defined boundaries (streets or property lines)
4. You can include multiple locations in one application

When completing the form, list Navigation Games as your local orienteering club and Maija Pratt (admin@navigationgames.org) as the local club contact. Navigation Games will provide guidance on program implementation.

### Hiring a Cartographer

Professional orienteering cartographers can create maps of your school campus, park, or camp property. They use LIDAR data, aerial imagery, OpenStreetMap data, and field survey to produce accurate maps. A school or park map typically costs several hundred dollars.

## Making Your Own Map

### Mapping Software

The sport follows international mapping standards:
- **ISSprOM** (International Specification for Sprint Orienteering Maps) for school, park, and urban maps
- **ISOM** (International Specification for Orienteering Maps) for forest maps

Two software options for creating maps:
- **[OCAD](https://www.ocad.com/)** (commercial, industry standard)
- **[Open Orienteering Mapper](https://www.openorienteeringmap.org/)** (free, open-source)

### Any Map Works Initially

Schools do not need professional orienteering maps to begin. Alternatives include:
- Existing school property maps
- Google Maps aerial imagery, printed and annotated
- Hand-drawn maps showing buildings, fields, paths, and other features
- Isometric (picture) maps that show a 3D view of the space

The key is that the map shows features students can see and match to reality. Even a rough sketch will work for early activities.

## Drawing Courses on Maps {#drawing-courses}

Once you have a base map, you draw the course on top of it. A pen works fine. Orienteering courses are drawn in purple or red, so they stand out from the map's own colors.

- **Start:** a triangle, centered on the start point.
- **Checkpoints:** a circle centered on the feature where the checkpoint is, with its number beside it. Put the number where it doesn't hide anything important.
- **Lines:** a straight line from the start to checkpoint 1, from 1 to 2, and so on, to show the order. The line is not the route. Runners choose their own way. Leave a gap where a line would cover an important feature.
- **Finish:** a double circle.

For a Score-O, leave out the lines, because students visit the checkpoints in any order.

### Purple Pen (Free Course Design Software)

[Purple Pen](https://purplepen.golde.org/) is a free Windows program for drawing orienteering courses on PDF maps. It produces print-ready course maps and supports both point-to-point and Score-O formats.

**Getting started:**
1. Import your map as a PDF
2. Place start, checkpoints, and finish
3. Print individual course maps or an all-checkpoints map with all checkpoints

**Tutorial videos:**
- [Getting Started with Purple Pen](https://www.youtube.com/results?search_query=purple+pen+orienteering+tutorial) (6 min, basic introduction)

### Other Options

- **Hand-marking** printed maps with permanent markers
- **Google Slides or PowerPoint** for creating course symbols on top of map images
