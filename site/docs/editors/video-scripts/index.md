# Video Scripts

Draft scripts for explainer videos. Each script covers one activity or one lesson plan, targeting 3-5 minutes of video for PE teachers and program leaders.

These are working documents for video production. They include visual direction notes (camera angles, screen graphics) alongside the narration.
