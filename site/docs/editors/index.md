# For Editors

Tools and reference material for curriculum editors. This section is not part of the published curriculum for teachers.

## What's here

- **[Editing Guide](editing-guide)** - Where to find files, how content is structured, and how to build and preview the site.
- **[Roadmap](roadmap)** - What's done, what's next, and what's deferred.
- **[Activities Table](content-table)** - Sortable table of all activities with icons, images, taglines, and metadata. Use this to review content at a glance and spot gaps.
- **[Video Scripts](video-scripts/)** - Draft scripts for explainer videos covering each activity and lesson plan. These are working documents for video production.
- **[Review Advisor Conversations](/review-conversations/)** - Read conversations people have had with the lesson plan advisor and leave feedback. Requires signing in with a navigationgames.org Google account.
