# Introduction to Core Activities

Each activity is one game you can run. The activity page tells you what it is and how to run it. Lesson plans tell you when, why, and in what order.

Related activities (readiness, variations, extensions) live with their parent core activity.

| Activity | Level | Summary |
|---|---|---|
| [Boundary Run](boundary-run) | 1 | Travel the boundary of the play area |
| [Gathering](gathering) | 1 | Return to the teacher on a signal |
| [Animal-O](animal-o) | 1 | Find animal checkpoints in order using a clue sheet |
| [Clothespin-O](clothespin-o) | 1 | Find hidden objects and describe their locations |
| [Geometric-O](geometric-o) | 1 | Use a simple map to do progressively harder courses |
| [Symbol-O](symbol-o) | 2 | Understand map symbols and the features they represent |
| [Map Walk](map-walk) | 2 | Walk a route together, matching map symbols to real features |
| [Score-O](score-o) | 2 | Visit as many checkpoints as possible in any order |
| [Point-to-Point](point-to-point) | 2 | Complete a course using an orienteering map |
