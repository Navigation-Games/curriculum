# Activities

Each activity is one game you can run. The activity page tells you what it is and how to run it. Lesson plans tell you when, why, and in what order.

The activities are organized in two groups:

- **Core activities** form the main teaching progression, from first boundary awareness to navigating a real course. The school lesson plans are built from these.
- **Camp and advanced activities** include the camp curriculum activities (compass work, relays, precision map reading) and game variations that build on the core progression.

Related activities (readiness exercises, variations, extensions) live on their parent activity's page under the Related Activities tab.

## Core activities

| Activity | Level | Summary |
|---|---|---|
| [Boundary Run](boundary-run) | 1 | Travel the boundary of the play area |
| [Gathering](gathering) | 1 | Return to the teacher on a signal |
| [Explore & Find](explore-and-find) | 1 | In pairs, explore to find animal checkpoints |
| [Animal-O](animal-o) | 1 | Find animal checkpoints in order using a clue sheet |
| [Clothespin-O](clothespin-o) | 1 | Find hidden objects and describe their locations |
| [Draw the Space](draw-the-space) | 1 | Draw a map of the play space as seen from above |
| [Geometric-O](geometric-o) | 1 | Use a simple map to do progressively harder courses |
| [Symbol-O](symbol-o) | 2 | Understand map symbols and the features they represent |
| [Map Walk](map-walk) | 2 | Walk a route together, matching map symbols to real features |
| [Score-O](score-o) | 2 | Visit as many checkpoints as possible in any order |
| [Point-to-Point](point-to-point) | 2 | Complete a course using an orienteering map |

## Camp and advanced activities

| Activity | Summary |
|---|---|
| [Map Discussion](map-discussion) | Guided group look at an orienteering map and its symbols |
| [Symbol Relay](symbol-relay) | Team relay to learn map symbols competitively |
| [Compass Basics](compass-basics) | Cardinal directions, setting the map, following a bearing |
| [Find Your Way Home](find-your-way-home) | Navigate back to home base from an unfamiliar spot |
| [Poison-O](poison-o) | Score-O where wrong checkpoints lose points |
| [Line-O](line-o) | Follow a line drawn on the map; find unmarked checkpoints along it |
| [Star Relay](star-relay) | Partners alternate out-and-back legs from the start (also called Star-O) |
| [Checkpoint Copy Relay](checkpoint-copy-relay) | Relay race to copy checkpoints from one map to another |
| [Window-O](window-o) | Navigate with parts of the map removed |
| [Vampire-O](vampire-o) | Score-O with a chase; vampires take your punch card |
| [Capture the Flag-O](capture-the-flag-o) | Capture the flag with flags at mapped locations |
