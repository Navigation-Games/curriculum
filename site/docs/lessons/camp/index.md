# Orienteering at Camp

Orienteering progressions for camp settings. Camps typically have larger outdoor spaces, longer sessions, and multi-day programs. The same activities used in school PE work at camp, framed around character development outcomes: independence, resilience, collaboration, and connection to nature.

| Progression | Status | Description |
|---|---|---|
| [Camp Intro](intro) | 3 sessions | First-time introduction to orienteering for campers |
| [Camp Skill Development](full) | 6 sessions | Multi-session progression building from map reading through compass and courses |
