# Camp Intro Curriculum

A first-time introduction to orienteering for campers. Three standalone sessions that can be run individually or as a short sequence. Covers boundaries, finding checkpoints with clue sheets, basic map use, and independent navigation.

## Sessions

| Session | What it covers |
|---|---|
| [1. **Animal-O**](./lesson-1) | Boundaries, clue sheets, finding checkpoints in order |
| [2. **Find Your Way Home**](./lesson-2) | Orient the map, navigate back to home base |
| [3. **Map Treasure Hunt**](./lesson-3) | Find checkpoints in any order using the map |
