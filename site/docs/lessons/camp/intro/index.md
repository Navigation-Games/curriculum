# Camp Intro Curriculum

A first-time introduction to orienteering for campers. Three standalone sessions that can be run individually or as a short sequence. Covers boundaries, finding checkpoints with clue sheets, basic map use, and independent navigation.

## Sessions

| Session | Title | What it covers |
|---|---|---|
| [1](./lesson-1) | Animal-O | Boundaries, clue sheets, finding checkpoints in order |
| [2](./lesson-2) | Find Your Way Home | Orient the map, navigate back to home base |
| [3](./lesson-3) | Map Treasure Hunt | Score-O: find checkpoints in any order using the map |
