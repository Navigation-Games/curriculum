# 5 - Map Checkpoints

> "Today we will find checkpoints on a real orienteering map"

## Overview

| | |
|---|---|
| **Time** | 30-60 minutes |
| **Space** | Gym, schoolyard, or local park |
| **Materials** | Orienteering maps, checkpoint markers (cones or flags), master map |
| **Setup** | Place checkpoints according to the master map |
| **Vocabulary** | Checkpoint, control, orient the map, route choice |

## Activities

- **Boundary Run**: Run the boundary and do warm-up exercises
- **Score-O**: Visit as many checkpoints as possible in any order within a time limit
- **Place Your Own Checkpoints**: Students place checkpoint markers using the map, then others find them
- **Poker-O** *(companion: extension)*: Collect "poker hands" at checkpoints
- **Poison-O** *(companion: extension)*: Score-O where visiting wrong checkpoints costs points

## Goals

### Orienteering Goals
- Use an orienteering map to locate checkpoints independently
- Visit checkpoints in any order, making route choices
- Place checkpoint markers at correct map locations
- Build confidence reading the map without step-by-step guidance

### PE Standards (SHAPE America)
- Use simple strategies and tactics (S2.E5)
- Move confidently and safely in open spaces (S2.E1, S4.E6)
- Work cooperatively and accept feedback from others (S4.E4, S4.E3)

## Delivery

1. Run the boundary and warm up
2. Review map orientation from lesson 4
3. Score-O: each student or pair gets a map with checkpoint circles. Visit as many as you can in the time limit. Any order you choose
4. Regroup and discuss: what strategies did you use? Did you plan a route or just run to the nearest one?
5. Place Your Own Checkpoints: give pairs a blank map and checkpoint markers. They choose locations, mark them on the map, and place the markers. Another pair uses their map to find them
6. Optional: Poker-O or Poison-O as a challenge round

## Reflection

- What strategy did you use to visit the most checkpoints?
- When you placed your own checkpoints, was it harder to place them or find them? Why?
- How did the map help you plan where to go?

## Extensions

- Poker-O: each checkpoint has a playing card. Collect the best poker hand
- Poison-O: some checkpoints are "poison" (not on your map). Visiting them costs points. Rewards careful map reading
- Set a class goal for total checkpoints visited
