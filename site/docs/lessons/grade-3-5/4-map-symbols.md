# 4 - Map Symbols

> "Today we will learn about orienteering maps and symbols"

## Overview

| | |
|---|---|
| **Time** | 30-60 minutes |
| **Space** | Gym, schoolyard, or local park |
| **Materials** | Checkpoints, large-scale orienteering map, map key (legend), master map, Symbol-O clue sheets |
| **Setup** | Place checkpoints by corresponding features |
| **Vocabulary** | Symbol, feature |

## Activities

- **Boundary Run**: Run the boundary; discuss inside/outside
- **Explore & Find** *(companion: readiness)*: In pairs, explore to find checkpoints
- **Map Discussion**: Compare the orienteering map to the picture map; learn symbols
- **Symbol-O**: Use symbol clue sheets to find checkpoints by feature type
- **Symbol Relay** *(companion: variation)*: Team relay to learn map symbols competitively

## Goals

### Orienteering Goals
- Understand map symbols and the features they represent
- Self-check using animal pictures as codes
- Compare orienteering map to picture map
- Match map symbols with corresponding real-world objects

### PE Standards (SHAPE America)
- Recognize the physical skills used in this activity (S2.E2)
- Plan your approach before doing the activity (S2.E5)
- Accept feedback from others (S4.E3)
- Give feedback to peers (S4.E4)

## Delivery

1. Run the boundary
2. Explore within the boundary to find checkpoints (or do Animal-O as warmup)
3. Learn about the orienteering map from the teacher:
   - Compare it to the picture map
   - Tell the teacher how to orient it
   - Describe features the teacher points out on the map
   - Run to and from features
   - Show map locations of checkpoints found while exploring
4. Learn the map symbols using the legend
5. Pair up; each pair gets a Symbol-O clue sheet and the corresponding animal clue sheet
6. Visit checkpoints matching the symbols; check with the animal clue sheet
7. Discuss with your partner what you each did well and what you could improve
8. Repeat with other courses

## Reflection

- How are the two maps (picture and orienteering) different?
- Which symbols were easier or harder to remember? Why?
- How did you work together?

## Extensions

- Do the course from memory
- Do the courses individually
- Symbol Relay as a team competition
