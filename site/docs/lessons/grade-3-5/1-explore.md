# 1 - Explore

> "In orienteering, you look for checkpoints within a boundary"

| | |
|---|---|
| **Time** | 30-60 minutes |
| **Space** | Gym, schoolyard, or local park |
| **Materials** | Checkpoints (cones with animal pictures), clue sheets |
| **Setup** | Place checkpoints around the space |
| **Vocabulary** | Boundary, gathering signal, orienteering, checkpoint |

<Tabs>
<TabItem value="goals" label="Goals" default>

### Orienteering Goals
- Stay within a boundary
- Gather on the teacher's signal
- Find checkpoints by exploring

### PE Standards (SHAPE America)
- Demonstrate locomotor skills (S1.E1, S1.E2)
- Engage actively in class (S3.E2)
- Follow rules and instructions (S4.E1)
- Accept corrective feedback from the teacher (S4.E3)
- Work cooperatively with others (S4.E5)

</TabItem>
<TabItem value="delivery" label="Delivery">

1. [**Boundary Run**](/activities/core/boundary-run): run the boundary; discuss what is inside and outside
2. [**Gathering**](/activities/core/gathering): practice gathering on the teacher's signal
3. Pair up
4. [**Explore & Find**](/activities/core/animal-o): explore to find animal checkpoints; return on a signal
5. **Animal Relay**: take turns running to checkpoints

</TabItem>
<TabItem value="reflection" label="Reflection">

- How many animals did you find? Which animal was the hardest to find?
- Did you stay within the boundary? How did you remember to do so?
- How fast did you go? How do you feel?
- When you played the Animal Relay, how do you check you are at the right place?
- Do you remember where the animals are?
- Were some animals easier or harder to find? Why?

</TabItem>
<TabItem value="extensions" label="Extensions">

- Use different movements and speeds during the boundary run
- Play Shrinking Boundary Tag
- Move the checkpoints to new locations and start over
- Have students draw a map of the area and checkpoint locations

</TabItem>
</Tabs>
