# 6 - Point-to-Point Navigation

> "Today we will be doing a real orienteering course using a map"

| | |
|---|---|
| **Time** | 30-60 minutes |
| **Space** | Gym, schoolyard, or local park |
| **Materials** | Orienteering flags or checkpoint markers, orienteering maps |
| **Setup** | Place checkpoints according to the master map |
| **Vocabulary** | Orient the map, route choice |

<TabItem value="goals" label="Goals" default>

### Orienteering Goals
- Orient a map and understand how it represents the real course
- Use the map to plan a route between checkpoints
- Complete a course in order: start, checkpoints, finish
- Make route choices based on the map

### PE Standards (SHAPE America)
- Use simple strategies and tactics (S2.E5)
- Move confidently and safely in open spaces (S2.E1, S4.E6)
- Work cooperatively and accept feedback from others (S4.E4, S4.E3)
- Give feedback to peers (S4.E4)

</TabItem>
<TabItem value="delivery" label="Delivery">

1. **Boundary Run**: run the boundary and warm up
2. **Map Walk**: walk a route together, matching symbols to features
3. **Partner Orienteering**: pair up, orient the map, agree on a route, visit each checkpoint in order; compare the code to confirm the correct checkpoint
4. **Solo Orienteering**: do the course individually several times to increase speed
5. Do the course in reverse order and without a map
6. Help fellow students by giving hints and teaching them how to read the map

</TabItem>
<TabItem value="reflection" label="Reflection">

- How did you determine which way to go for each checkpoint?
- What shortcuts between checkpoints did you find?
- If you were at a wrong checkpoint, how did you figure out where you needed to go instead?

</TabItem>
<TabItem value="extensions" label="Extensions">

- Relay race: divide into teams, each member completes the course and tags the next
- Challenge students to run to three checkpoints in order without a map
- **Score-O**: visit checkpoints in any order within a time limit
- **Poker-O**: collect "poker hands" at checkpoints
- **Poison-O**: wrong checkpoints cost points

</TabItem>
