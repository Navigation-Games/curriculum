# 2 - Gathering

> "You can go anywhere in the boundary, but you must come back"

| | |
|---|---|
| **Time** | 15-30 minutes |
| **Space** | Gym, schoolyard, or local park |
| **Materials** | Whistle, flag, or other gathering signal |
| **Setup** | Define a clear boundary and establish a central gathering location |
| **Vocabulary** | Boundary, gathering signal |

<Tabs>
<TabItem value="goals" label="Goals" default>

### Orienteering Goals
- Move freely within the boundary with confidence
- Maintain awareness of the gathering signal while moving
- Respond quickly and safely to the signal
- Communicate and strategize with the group to improve gathering time

### PE Standards (SHAPE America)
- Demonstrate locomotor skills (S1.E1, S1.E2)
- Engage actively in class (S3.E2)
- Work cooperatively with others (S4.E5)

</TabItem>
<TabItem value="delivery" label="Delivery">

1. [**Boundary Run**](/activities/core/boundary-run): quick review of the boundary
2. [**Gathering**](/activities/core/gathering): explain the gathering signal; students move freely within the boundary
3. Signal. Count how many seconds it takes the group to gather
4. Repeat. Encourage students to strategize to gather faster

</TabItem>
<TabItem value="reflection" label="Reflection">

- What strategies helped the group gather quickly? How did you work together?
- How did you stay aware of the signal while moving?
- What are examples of times that you need to pay attention to more than one thing?

</TabItem>
<TabItem value="extensions" label="Extensions">

- Use different signals (visual only, varied sounds)
- Add movement constraints (skipping, animal movements)
- Play tag between gathering signals
- Time the group and track improvement on a whiteboard

</TabItem>
</Tabs>
