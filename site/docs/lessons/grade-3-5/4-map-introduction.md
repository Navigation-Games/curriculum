# 4 - Map Introduction

> "Today we will learn about orienteering maps and symbols"

| | |
|---|---|
| **Time** | 30-60 minutes |
| **Space** | Gym, schoolyard, or local park |
| **Materials** | Checkpoints, large-scale orienteering map, map key (legend), master map, Symbol-O clue sheets |
| **Setup** | Place checkpoints by corresponding features |
| **Vocabulary** | Symbol, feature, orient the map |

<TabItem value="goals" label="Goals" default>

### Orienteering Goals
- Understand what an orienteering map is and how it differs from simpler maps
- Orient a map to match the real world
- Learn map symbols and match them to real features
- Walk a route while reading the map

### PE Standards (SHAPE America)
- Recognize the physical skills used in this activity (S2.E2)
- Plan your approach before doing the activity (S2.E5)
- Accept feedback from others (S4.E3)
- Give feedback to peers (S4.E4)

</TabItem>
<TabItem value="delivery" label="Delivery">

1. [**Boundary Run**](/activities/core/boundary-run): run the boundary
2. Explore within the boundary to find checkpoints (or [**Animal-O**](/activities/core/animal-o) as warmup)
3. **Map Discussion**: introduce the orienteering map
   - Compare it to the pattern maps from lesson 3
   - Tell the teacher how to orient it
   - Describe features the teacher points out on the map
   - Run to and from features
   - Show map locations of checkpoints found while exploring
4. Learn the map symbols using the legend
5. **Map Walk**: walk a route as a group, matching symbols to real features along the way
6. Pair up; each pair gets a **Symbol-O** clue sheet and the corresponding animal clue sheet
7. Visit checkpoints matching the symbols; check with the animal clue sheet
8. Discuss with your partner what you each did well and what you could improve

</TabItem>
<TabItem value="reflection" label="Reflection">

- How is the orienteering map different from the pattern maps we used before?
- Which symbols were easier or harder to remember? Why?
- How did you orient the map? What landmarks helped?

</TabItem>
