# Teach at a School

Structured lesson progressions for PE classes, organized by grade band. Each progression builds skills over multiple sessions, moving from basic spatial awareness to independent map navigation. Activities are aligned to SHAPE America PE standards.

| Grade Band | Status | Description |
|---|---|---|
| [Grade K-2](grade-k-2) | Planned | Boundary exploration, gathering, spatial awareness through play |
| [Grade 3-5](grade-3-5) | Available | Six-lesson progression from boundaries to map navigation |
| [Grade 6+](grade-6-plus) | Planned | Compass work, route choice, competitive formats |
