## Goals

### Orienteering Goals
- Know where home base (start/finish) is from anywhere in the boundary
- Navigate back to home base from any position in the area
- Develop spatial awareness and a sense of direction within the space
- Respond quickly to the gathering signal as practice for returning

### PE Standards (SHAPE America)
- Demonstrate locomotor skills (S1.E1, S1.E2)
- Engage actively in class (S3.E2)
- Work cooperatively with others (S4.E5)

## Delivery

1. [**Boundary Run**](/activities/core/boundary-run): quick review; establish home base with a flag or cone in the center
2. Students walk to different spots (corners, edges). Can they point to home base from where they are?
3. [**Gathering**](/activities/core/gathering): students move freely within the boundary; return to home base on the signal; count how many seconds it takes
4. Repeat: spread out further. Encourage students to find home base from the farthest spots.
5. Discuss: how did you know where to go?

## Reflection

- How did you know where home base was?
- Was it harder to return from far away? What helped?
- In orienteering, you use a map to get back to the finish. What did you use today?

## Extensions

- Use a different signal (visual only, varied sounds)
- Time the group; try to improve over several rounds
- Move home base to a new location; reset and find it again
- Students close eyes at home base, walk to a random spot, then find their way back
