# Grade 3-5 Orienteering Curriculum

Grades 3-5 (ages 9-11). Six lessons that build from basic spatial awareness to independent navigation with maps. Each lesson adds one new concept on top of the last.

## Learning Progression

| Lesson | What it adds | Main Activity |
|---|---|---|
| [1. **Boundary**](1-boundary.md) | Here is where you can go | [Boundary Run](/activities/core/boundary-run) |
| [2. **Return**](2-return.md) | Find your way back to home base from anywhere | [Gathering](/activities/core/gathering) |
| [3. **Explore & Find**](3-explore-and-find.md) | There are things out there; go find them | Explore & Find |
| [4. **Clue Sheets**](4-clue-sheets.md) | Find them in this specific order | [Animal-O](/activities/core/animal-o) |
| [5. **Map Readiness**](5-map-readiness.md) | Spatial relationships, orienting, connecting a map to the space | [Geometric-O](/activities/core/geometric-o) |
| [6. **Maps**](6-maps.md) | Navigate using a real orienteering map | [Map Walk](/activities/core/map-walk), [Score-O](/activities/core/score-o) |

Plan for six class periods, one per lesson. Lessons 5 and 6 often extend across two sessions, and the first three lessons can sometimes be combined for groups that move quickly. The sequence is the same regardless of pacing.

[**Indoor Orienteering**](a-indoor-orienteering.md) is an alternative that uses a basketball court, covering lessons 5-6.

## Activities Referenced

### Core Activities

| Activity | First Appears | Description |
|---|---|---|
| [Boundary Run](/activities/core/boundary-run) | Lesson 1 | Travel the boundary of the play area |
| [Gathering](/activities/core/gathering) | Lesson 1 | Return to home base on the gathering signal |
| Explore & Find | Lesson 1 | In pairs, explore to find animal checkpoints |
| [Animal-O](/activities/core/animal-o) | Lesson 2 | Find animal checkpoints in order using clue sheets |
| [Geometric-O](/activities/core/geometric-o) | Lesson 3 | Use a simple map to do progressively harder courses |
| [Map Walk](/activities/core/map-walk) | Lesson 4 | Walk a route matching map symbols to real-world features |
| [Score-O](/activities/core/score-o) | Lesson 5 | Visit as many checkpoints as possible in any order within a time limit |
| Point-to-Point | Lesson 6 | Navigate a course visiting controls in order using a map |

### Companion Activities

| Parent | Activity | Type | Description |
|---|---|---|---|
| Boundary Run | Hot or Cold | Extension | Use temperature clues to direct a partner to a secret location |
| Boundary Run | Shrinking Boundary Tag | Extension | Play tag while the boundary gets smaller |
| Animal-O | Clothespin-O | Extension | Find hidden objects and describe their locations |
| Animal-O | Animal Relay | Variation | Take turns running to animal checkpoints |
| Geometric-O | Geometric Readiness | Readiness | Spatial vocabulary and map orientation exercises |
| Geometric-O | Find the Cone | Readiness | Stand by the circled cone with your map oriented |
| Map Walk | Symbol-O | Readiness | Learn orienteering map symbols by finding features |
| Symbol-O | Symbol Relay | Variation | Team relay to learn map symbols competitively |
| Geometric-O | Word Bank Orienteering | Variation | Guide a partner using only approved spatial words |
| Geometric-O | Napkin-O | Extension | Communication challenge with hidden animal pictures |
| Geometric-O | Basketball-O | Variation | Orienteering on a basketball court map |
| Score-O | Poison-O | Extension | Score-O where wrong checkpoints lose points |
| Score-O | Poker-O | Extension | Collect "poker hands" at checkpoints |
| Basketball-O | Pacman-O | Extension | Line tag played while completing courses |
