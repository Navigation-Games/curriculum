# Grade 3-5 Orienteering Curriculum

Grades 3-5 (ages 9-11). Six lessons that build from basic spatial awareness to independent navigation with maps. Each lesson adds one new concept on top of the last.

## Learning Progression

| Lesson | What it adds | Main Activity |
|---|---|---|
| [1. **Boundary & Return**](1-boundary-and-return) | Here is where you can go; come back when you hear the signal | [Boundary Run](/activities/core/boundary-run), [Gathering](/activities/core/gathering) |
| [2. **Explore & Find**](2-explore-and-find) | There are things out there; go find them | Explore & Find |
| [3. **Clue Sheets**](3-clue-sheets) | Find them in this specific order | [Animal-O](/activities/core/animal-o) |
| [4. **Map Readiness**](4-map-readiness) | Spatial relationships, orienting, connecting a map to the space | [Geometric-O](/activities/core/geometric-o) |
| [5. **Map Symbols**](5-map-symbols) | Symbols tell you what features are on the ground | [Symbol-O](/activities/core/symbol-o), [Map Walk](/activities/core/map-walk) |
| [6. **Maps**](6-maps) | Navigate using a real orienteering map | [Score-O](/activities/core/score-o), [Point-to-Point](/activities/core/point-to-point) |

Plan for six class periods, one per lesson. Lessons 4 through 6 often extend across two sessions, and the first two lessons can sometimes be combined for groups that move quickly. The sequence is the same regardless of pacing.

[**Indoor Orienteering**](a-indoor-orienteering.md) is an alternative that uses a basketball court, covering lessons 4-6.

## Activities Referenced

### Core Activities

| Activity | First Appears | Description |
|---|---|---|
| [Boundary Run](/activities/core/boundary-run) | Lesson 1 | Travel the boundary of the play area |
| [Gathering](/activities/core/gathering) | Lesson 1 | Return to home base on the gathering signal |
| Explore & Find | Lesson 2 | In pairs, explore to find animal checkpoints |
| [Animal-O](/activities/core/animal-o) | Lesson 3 | Find animal checkpoints in order using clue sheets |
| [Geometric-O](/activities/core/geometric-o) | Lesson 4 | Use a simple map to do progressively harder courses |
| [Symbol-O](/activities/core/symbol-o) | Lesson 5 | Find checkpoints by matching map symbols to real features |
| [Map Walk](/activities/core/map-walk) | Lesson 5 | Walk a route matching map symbols to real-world features |
| [Score-O](/activities/core/score-o) | Lesson 6 | Visit as many checkpoints as possible in any order within a time limit |
| [Point-to-Point](/activities/core/point-to-point) | Lesson 6 | Navigate a course visiting checkpoints in order using a map |

### Companion Activities

| Parent | Activity | Type | Description |
|---|---|---|---|
| Boundary Run | Hot or Cold | Extension | Use temperature clues to direct a partner to a secret location |
| Boundary Run | Shrinking Boundary Tag | Extension | Play tag while the boundary gets smaller |
| Animal-O | Animal Relay | Variation | Take turns running to animal checkpoints |
| Geometric-O | Geometric Readiness | Readiness | Spatial vocabulary and map orientation exercises |
| Geometric-O | Find the Cone | Readiness | Stand by the circled cone with your map oriented |
| Geometric-O | Word Bank Orienteering | Variation | Guide a partner using only approved spatial words |
| Geometric-O | Napkin-O | Extension | Communication challenge with hidden animal pictures |
| Geometric-O | Basketball-O | Variation | Orienteering on a basketball court map |
| Symbol-O | Symbol Relay | Variation | Team relay to learn map symbols competitively |
| Score-O | Poison-O | Extension | Score-O where wrong checkpoints lose points |
| Score-O | Poker-O | Extension | Collect "poker hands" at checkpoints |
| Geometric-O | Pacman-O | Extension | Line tag played while completing courses |
