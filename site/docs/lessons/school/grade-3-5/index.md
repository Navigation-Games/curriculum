# Grade 3-5 Orienteering Curriculum

Grades 3-5 (ages 8-11). Six lessons that build from basic spatial awareness to independent navigation with maps. Each lesson adds one new concept on top of the last.

These lessons cover concept sequence entries 1-11 (Pre-Map through Map Introduction), 12-13 (Symbols), and intro to 16-21 (Navigation with Maps, Score-O). Communication (#36-41) and Individual Development (#42-45) are woven throughout.

## Learning Progression

| Lesson | Theme | Key Activities | Concepts Introduced |
|---|---|---|---|
| 1. **Getting Started** | Boundary, return, and first exploration | Boundary Run, Gathering, Explore & Find | Boundaries, Return, Searching, Safety |
| 2. **Clue Sheets** | Follow a sequence, describe locations | Animal-O (in order), Clothespin-O or map drawing | Following a sequence, Confirming location, Spatial communication |
| 3. **Orienting the Map** | Connect a map to the space | Geometric-O (progressively harder courses) | Map as picture, Pattern matching, Orienting, Spatial relationships |
| 4. **Map Symbols** | Read an orienteering map | Symbol-O, Map Walk, Symbol Relay | Basic symbols, Legend, Connecting symbols to terrain |
| 5. **Navigate with a Map** | Independent map navigation | Score-O, Poison-O | Route choice, Planning, Independence |
| 6. **Orienteering Courses** | Point-to-point orienteering | Point-to-Point courses | Following linear features, Junctions, Choosing challenge |

Plan for six class periods, one per lesson. Lessons 3 and 5 often extend across two sessions. The first lesson combines boundary, gathering, and exploration into a single session. The sequence is the same regardless of pacing.

**Indoor Orienteering** is an alternative that covers the Geometric-O and Map concepts using a basketball court.

## Notes for 3-5

- **Lesson 1 combines three activities:** For grades 3-5, separate lessons on boundary, gathering, and explore & find are too slow. One session covers all three, spending about 10 minutes on each.
- **Clothespin-O in Lesson 2:** After Animal-O, Clothespin-O bridges from clue sheets to spatial communication. Students describe where they found hidden objects, building the vocabulary they'll need for map work.
- **Geometric-O is the turning point:** Lesson 3 is where students first use a map. The whiteboard introduction is essential. Do not skip it.
- **Roles:** By Lesson 2, introduce Finder and Helper roles. Students who finish their course can help others (with rules about what Helpers can say). See concept #37 in the skill sequence.
- **From memory:** In both Animal-O and Geometric-O, have students repeat courses from memory. This develops spatial memory (concept #5) and is highly motivating.

## Activities Referenced

### Core Activities

| Activity | First Appears | Description |
|---|---|---|
| Boundary Run | Lesson 1 | Travel the boundary of the play area |
| Gathering | Lesson 1 | Return to home base on the gathering signal |
| Explore & Find | Lesson 1 | In pairs, explore to find animal checkpoints |
| Animal-O | Lesson 2 | Find animal checkpoints in order using clue sheets |
| Geometric-O | Lesson 3 | Use a simple map to do progressively harder courses |
| Map Walk | Lesson 4 | Walk a route matching map symbols to real-world features |
| Score-O | Lesson 5 | Visit as many checkpoints as possible in any order within a time limit |
| Point-to-Point | Lesson 6 | Navigate a course visiting controls in order using a map |
