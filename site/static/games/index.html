Map games

Games where navigating is the fun. Some you play outside with a map, some on a screen, and some both ways. The ones we invent get a simulator, so we can try out rules before trying them with real people.

Our games

Road Block

Real lifeSimulator

Teams race to visit every checkpoint on a trail network, traveling only on trails. The team with the most players at an intersection blocks it, so a team has to decide when to split up, when to stick together, and when to stand guard.

Simulator How the simulator works The school activity

Every activity in our curriculum is a real-life game too, from Animal-O to Vampire-O, and More Games has a few extras like Maze-O.

Games from elsewhere

Catching Features

On a computer

A 3D orienteering game for Windows. You run courses through virtual terrain with an orienteering map, and you can race other people online. Clubs and coaches use it to practice map reading and route choice. There's a free demo; the full version is paid.

catchingfeatures.com

MapRun

Real lifePhone app

Courses with virtual checkpoints: you carry a map, and the phone app registers each checkpoint by GPS and times you. Clubs set up MapRun courses in towns, parks and forests that you can run any time, with no flags to put out.

MapRun site

Rogaining

Real life

Long-distance team navigation. Teams choose which checkpoints to visit and in what order before time runs out, like a big Score-O (our Map Treasure Hunt). Championships last 24 hours; most events are shorter.

International Rogaining Federation
