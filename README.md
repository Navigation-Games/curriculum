# Navigation Games — Orienteering Curriculum

Reorganizing the [Navigation Games](https://navigationgames.org) orienteering curriculum around a sequence of learning goals, migrating content from Google Sites to a static site (Docusaurus or MkDocs + GitHub Pages).

## Learning Goal Sequence (Level 2)

| # | Learning Goal | Core Activities |
|---|---|---|
| 1 | Explore | Boundary Run, Gathering |
| 2 | Clue Sheets | Animal-O |
| 3 | Patterns | Geometric Readiness, Geometric-O |
| 4 | Picture the Space | Explore & Find, Map Walk, Map Discussion |
| 5 | Map Symbols | Symbol-O, Symbol Relay |
| 6 | Orienteering Courses | Score-O, Courses (Point-to-Point), Compass Basics |
| A | Indoor Orienteering | Classroom/gym variants |

## Project Structure

- `background/` — source materials, reference docs, and context files
- `docs/` — curriculum content (Markdown, organized by learning goal) *(coming soon)*
