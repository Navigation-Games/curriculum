## Lesson ordering: Patterns vs Picture the Space

The GitBook (Level 2) and the Google Site (Grade 3-5) use different ordering:

**GitBook:** Explore > Clue Sheets > Patterns > Picture the Space > Map Symbols > Courses
**Google Site:** Boundary Runs > Animal-O > Picture Maps > Geometric-O > Symbols > Courses

The GitBook puts Geometric-O (Patterns) before picture maps. The Google Site reverses them. Both orderings are defensible. Check with Kieran if there's a reason the Google Site changed the order.

### Picture the Space: probably not in the main progression

Most teachers won't have a picture (isometric) map available, so "Picture the Space" doesn't belong as a required lesson in the standard progression. However, two things from this lesson are worth keeping:

1. **Drawing maps.** Having kids draw their own maps of the space fits naturally into the progression and doesn't require special materials. Several other lessons already list "have students draw a map" as an extension. Could this become a more intentional part of the sequence rather than an optional extension?

2. **Visualizing the space.** The concept of "picturing the space" (building a mental map, connecting what you see to what's on the map) is important. The name captures something real even if the specific lesson built around isometric maps is too specialized. Could this concept be woven into Patterns or Map Symbols instead of standing alone?

**Decision:** Dropped Picture the Space as a standalone lesson. Drawing maps is now a fleshed-out extension in lesson 2 (Clue Sheets/Animal-O). The concept of visualizing space (mental maps, connecting physical space to representation) still threads through Patterns and Map Symbols but doesn't need its own lesson.

The progression is now 5 lessons + 1 alternative:
1. Explore
2. Clue Sheets
3. Patterns
4. Map Symbols
5. Orienteering Courses
A. Indoor Orienteering

## SI (electronic timing) pulled out of core activities

The scripts doc has the same SI system instructions (Clear, Start, Finish, Download) copy-pasted into almost every activity. SI is an enhancement, not core.

**Decision:** Remove SI from all core activity descriptions. Create a single SI/electronic timing page (probably under Equipment) and reference it from activities that support it.

## Map Symbols generalized to Map Introduction; Map Checkpoints added

"Map Symbols" was too narrow a name for lesson 4. Renamed to **Map Introduction** to cover the broader concept: introducing the orienteering map itself, learning symbols, and walking a route with the map.

Added **Map Checkpoints** as a new lesson 5, between Map Introduction and Orienteering Courses. This lesson includes Score-O and a "Place Your Own Checkpoints" activity where students set markers using the map. Bridges the gap between learning symbols (lesson 4) and running full point-to-point courses (lesson 6).

The progression is now 6 lessons + 1 alternative:
1. Explore
2. Clue Sheets
3. Patterns
4. Map Introduction
5. Map Checkpoints
6. Orienteering Courses
A. Indoor Orienteering
