## 1. Activity Content That Should Move to Lesson Plans

The principle: activities own *what it is and how to run it*. Lesson plans own *sequencing, transitions, warm-ups, and when to use it*.

### Geometric-O: the main offender

**Step 1 ("Animal-O warm-up")** is sequencing, not part of Geometric-O itself. The lesson plan (Lesson 3) already says "Warm up individually with Animal-O." The activity page should not prescribe which other activity to do first.

**Step 2 ("Whiteboard introduction")** is borderline. The whiteboard demo *is* how you teach Geometric-O, so it belongs in the activity. But the current framing blends it with the spatial-description exercises (Step 3), making the activity feel like a mini-lesson plan. Consider:
- Keep the whiteboard introduction as core Geometric-O setup/delivery
- Move "Spatial descriptions" (Step 3) to a companion activity ("Geometric Readiness") or to the lesson plan delivery. The lesson index already lists "Geometric Readiness" as a companion, but it doesn't have its own content yet

**Recommendation:** Remove Step 1 (Animal-O warm-up) from Geometric-O. Rename Steps 2-4 as the actual steps. Decide whether "Spatial descriptions" becomes a Geometric Readiness companion or stays as an optional warm-up within Geometric-O.

### Animal-O Script: teaches Boundary Run

The Animal-O script starts with a full "Boundaries" section (lines 122-136) that duplicates what Boundary Run does. This is sequencing: "first do boundaries, then do Animal-O." The lesson plan already handles this (Lesson 2 Delivery: "1. Run the boundary").

**Recommendation:** Remove the Boundaries section from the Animal-O script. The script should start at "Visiting Cones Together." Add a note like "Prerequisite: students should have completed a Boundary Run."

### Boundary Run and Gathering: clean

These two activities stay focused on what they are. Progression sections describe how to scale the activity itself, not how to sequence it with other activities. No changes needed.

### General pattern: Scripts

Scripts live in activities, not lesson plans. A teacher picking up just one activity should be able to teach it from the activity page alone. This is the right call. But scripts should not include content that belongs to *other* activities (like boundaries in the Animal-O script).

### Reflection questions: split allegiance

Currently reflection questions appear in:
- Activity one-pagers (CompactOnly)
- Lesson plans (Reflection tab)
- NOT in the activity full view (FullOnly has no Reflection tab)

This is actually fine as-is. The one-pager is a standalone handout, so it needs reflection. The full activity page defers to the lesson plan for reflection. No change needed, but worth being intentional about this: **reflection belongs to lesson plans, and one-pagers include it only because they're standalone handouts.**

### Geometric-O: different framing styles

**One-pager goals** (nouns/concepts): Simple maps, Identifying landmarks, Spatial relationships, Orientation, Fixing mistakes

**Full-view goals** (verbs/behaviors): Read a simple map and connect it to physical space, Use landmarks to orient a map, Describe checkpoint locations using spatial vocabulary, Identify and fix orientation mistakes, Complete progressively harder courses

**Recommendation:** Since the one-pagers have been more carefully worked on per the user's note, keep the one-pager framing but make the full view consistent. One-pagers have reflection questions; full views do not. One-pagers have extensions; full views have Progression sections in the "How to Run It" tab. These serve similar but distinct purposes:
- **Progression** = how to scale difficulty within the activity itself
- **Extensions** = what to do next (companion activities, additional challenges, or cross-curricular connections)

This distinction is fine. The one-pager extensions should draw from the Companions tab in the full view.

## 4. SHAPE America Standards

### The old codes are outdated

SHAPE America released completely revised National PE Standards in **March 2024** (4th edition). The old S1.E1-style codes the lessons currently use come from the 2013 framework. The new standards are a significant structural overhaul:

**Old (2013): 5 standards, per-grade outcomes**
1. Motor skills and movement patterns
2. Movement concepts, strategies, tactics
3. Fitness knowledge and activity levels
4. Responsible personal and social behavior
5. Values physical activity

**New (2024): 4 standards, grade-span indicators**
1. Develops a variety of motor skills
2. Applies knowledge related to movement and fitness concepts
3. Develops social skills through movement
4. Develops personal skills, identifies personal benefits of movement, and chooses to engage in physical activity

Key changes:
- Old Standard 3 (fitness) folded into new Standard 2
- Old Standards 4+5 (behavior + values) split into new Standards 3 (social) and 4 (personal)
- Grade-level outcomes (S1.E1.3) replaced by grade-span indicators (1.5.1 = Standard 1, grades 3-5, indicator 1)
- Grade spans: PreK-2, 3-5, 6-8, 9-12

### Mapping old codes to new standards

| Old Code | Old Meaning | New Standard |
|---|---|---|
| S1.E1, S1.E2 | Locomotor skills | Standard 1 (motor skills) |
| S2.E1 | Movement concepts | Standard 2 (concepts) |
| S2.E2 | Pathways/shapes/levels | Standard 2 |
| S2.E5 | Strategies/tactics | Standard 2 |
| S3.E2 | Fitness knowledge | Standard 2 (fitness folded in) |
| S4.E1 | Rules/instructions | Standard 3 or 4 |
| S4.E3 | Accepting feedback | Standard 3 (social) |
| S4.E4 | Working with others | Standard 3 (social) |
| S4.E5 | Cooperation | Standard 3 (social) |
| S4.E6 | Safety | Standard 4 (personal) |
| S5.E4 | Social interactions | Standard 3 (social) |

### Recommendation

1. **Download the free Educator Kit PDF** from SHAPE America (shapeamerica.org) to get the complete grade-span indicators for 3-5
2. **Update lesson plans** to reference the new 2024 codes
3. **Create a reference page** (site/docs/reference/standards.md) mapping curriculum activities to the new standards
4. **Move standards out of activities** entirely. Standards belong to lesson plans and the reference page, not to individual activity descriptions

### Where standards currently live

Standards are in lesson plan Goals tabs only (not in activities). This is correct. No activity page references SHAPE codes. The standards reference page would be a useful addition for PE teachers evaluating the curriculum.
